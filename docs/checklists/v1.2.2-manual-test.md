# v1.2.2 手测清单

> 测试包：`releases/epytor-vscode-1.2.2.vsix`
>
> **状态口径**：`[x]` **只表示 owner 明确确认过**（注明日期与测试包）。本版为四个目录/锚点相关修复。
>
> 上一版清单见 [`v1.2.1-manual-test.md`](v1.2.1-manual-test.md)。

## 1. 目录面板输入时不再闪动

* [ ] 打开一个有多个标题的文档、展开目录，在**正文段落**里连续打字 → 目录内容**不闪**，目录自身的滚动位置不被重置
* [ ] 打字过程中当前章节高亮**持续保持**，不出现「灭一下再亮」

## 2. 点击目录项定位准确

* [ ] 依次点击目录**每一项** → 高亮落在**被点的那一项**（重点：点**第一项**，此前完全没有高亮）
* [ ] 点完不滚动、静置几秒 → 高亮不自己跑
* [ ] **短文档**（内容不足以滚动、或只能滚一点点）里同样准确——此前点第 1 项会落到最后一项
* [ ] 点击钉住后滚动正文 → 高亮交回滚动跟随（钉住自动解除）
* [ ] 点吸顶条上的标题行 → 高亮同样正确

## 3. 目录项整行可点

* [ ] 点目录项的**文字左侧空白 / 上下边缘 / 文字右侧空白** → 都能跳转（本版修的就是这个）
* [ ] 点**折叠箭头** → 只折叠/展开，**不**跳转

## 4. 文档内锚点链接

* [ ] 写 `[去第一章](#第一章)`（中文原文写法）→ 点击能跳，且目录高亮落在被跳的那一项
* [ ] 目标标题含中文、而链接是**百分号编码**写法（如 `#%E7%AC%AC%E4%B8%80%E7%AB%A0`）→ 点击**能跳**（修复前没反应）
* [ ] 锚点指向不存在的标题 → 安静不动，不跳错、不报错

## 5. 回归抽查

* [ ] 目录开/关、拖宽度、窗口变窄自动收起仍正常
* [ ] 标题折叠、吸顶条仍正常
* [ ] 编辑后保存内容与保存前一致（未因本版改动引入保存差异）

复现路径：`code --install-extension releases\epytor-vscode-1.2.2.vsix --force` → 重载窗口（`Developer: Reload Window`）→ 打开任意 `.md`。

> 注：本扩展的 webview 保活，装完**必须重载窗口**，否则仍跑旧代码。
