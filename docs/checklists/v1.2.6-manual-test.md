| 包 | 版本 | 进产物 | 本版行为风险 |

## 1. 行内公式与光标（对应 `prosemirror-view` 1.42.6 的 dummy IMG，重点测这块）

**现象（升级后可能）**：行内原子节点前多出一个 `<img class="ProseMirror-separator">`（不可见 dummy 节点，用于修正 Safari/Firefox 的光标跳位）。若 CSS 的 `:first-child` 规则撞上它，可能撑开间距或影响光标落点。

* [ ] 新建文档，**第一行**就写一个行内公式 `$x$`（前面不要有文字），光标能正常进入公式、左右方向键能跨过它
* [ ] 同上，在公式**最前面**按退格 → 不崩、不吞掉公式、光标行为正常
* [ ] 段落中间（前后都有文字）的行内公式：光标进入/退出、双击选中均正常
* [ ] 中文输入法（IME）在公式**旁边**起笔输入中文 → 输入正常、不丢字、不跳位
* [ ] 块首公式那一行**视觉上**没有莫名多出的空隙（分隔符 DOM 已确认存在，这里只看像素）

## 2. 表格内行内公式（`:first-child` 边界，子代理点名的未确认项）

**风险**：epytor 有 `.ProseMirror td/th > *:first-child { margin-top: 0 }` 这类首子元素规则；若单元格里首个块就是行内公式，dummy IMG 会抢占 `:first-child`。

> **已实测排除**：分隔符落在 `<p>` **内部**，被 `:first-child` 选中的仍是最外层 `<p>`，不会抢。下面两条只需看视觉间距实测值。

* [ ] 表格单元格**以行内公式开头**（如 `| $x$ 说明 |`）→ 单元格顶部间距与该格其他行一致，没有莫名多出的空隙
* [ ] 同上单元格，光标能正常点进去、能编辑公式
* [ ] 表格里放**块级公式**（独占一行的 `$$...$$`）→ 渲染、保存往返正常
