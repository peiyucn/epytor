## 1. 本版修复（重点测这块）

**现象（1.2.4）**：打开一个含「松散列表」（列表项之间有空行）的文件，**不做任何编辑**直接保存，空行被删掉、列表从松散变紧凑；自动保存也会触发。
**期望（1.2.5）**：未编辑保存与原文**逐字一致**（`git diff` 为空）。

* [ ] 准备一个松散列表文件（示例见下），打开它、**什么都不改**，`Ctrl+S` → 保存后文件内容与保存前**逐字一致**
* [ ] 同上文件，等几秒让自动保存触发（`files.autoSave` 打开时）→ 文件同样**不被改写**
* [ ] CRLF 行尾的松散列表文件，未编辑保存 → 仍逐字一致且**仍是 CRLF**
* [ ] 连续保存两次（都不编辑）→ 两次都不改写
* [ ] 编辑任意一处（例如改一个词）后保存 → 改动正常落盘，未编辑的部分保持原写法

示例松散列表（复制到 `.md` 里）：

```markdown
# 测试

- [x] 已完成

- 普通项一
- 普通项二
```

## 2. 任务列表连续回车（本版第二条修复）

**现象（修复前）**：嵌套任务列表里在空任务项上回车，会先变成普通圆点项、再按一次才退出列表。
**期望**：空任务项回车 = 提升一级（顶层即退出列表），全程保持任务项、不出现圆点项。

* [ ] 建一个嵌套任务列表（示例见下），光标放到「内层」末尾，**连续按 3 次回车**：
  - 第 1 次 → 新建一个未勾选的内层任务项
  - 第 2 次 → 该项**提升到外层**（仍是任务项、未勾选），**不出现圆点项**
  - 第 3 次 → 继续提升 / 退出列表，全程无圆点项
* [ ] 顶层任务列表连续回车 → 新项未勾选；空项回车直接退出列表（与之前一致）

```markdown
- [ ] 外层
  - [ ] 内层
```
