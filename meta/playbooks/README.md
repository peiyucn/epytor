# 任务步骤

任务入口在根 `AGENTS.md` 的 C1；本文件只说明怎么用 playbook。

## 开工前

1. 读项目 `AGENTS.md` 的文件头、`## 2`–`## 5` 段和项目文档；`## 1` 共享契约已默认加载；
2. 复述目标、非目标、假设；
3. 写一句“看到什么算完成”；
4. 打开对应 playbook；
5. 不确定先查；查不到就说明，不猜。

## 怎么用

1. 把步骤原样拷进 todo；
2. 不跳步；确实不适用的步骤保留，写 `skip: 原因`；
3. 每步完成时写证据，不是只打勾；
4. 结束时按 playbook 的输出格式汇报。

## 新增 playbook

按 [TEMPLATE.md](TEMPLATE.md) 写；每一步写清“做 / 调用 / 证据”。
