# Proxy

> 何时用：git 或 agent 宿主进程需要走代理。
> 何时不用：直连可用。

## 用法

- git 与 agent 宿主进程均不读取系统代理；
- git 用一次性参数，宿主进程设环境变量并开启环境代理支持；
- 不写入配置文件。

## 本机网络

- GitHub 国内直连不稳定；
- 代理由 Clash VPN 提供，端口不固定，本机见过 7897 / 7890，但不保证；
- 先探测当前端口，不要凭上一次的端口盲试；
- 可用时 git 用一次性参数：

```text
-c http.proxy=http://127.0.0.1:<port>
-c https.proxy=http://127.0.0.1:<port>
```

- 端口不通 / 代理未启动：报告网络阻塞，停止连续重试，问 owner 是否启动 Clash。

## 检查

- 请求实际走代理的证据。
