# Fix Root Causes

> 何时应用：调试、修 bug、同一问题反复出现时。

## 判断

从症状往回追，找到**第一个出错的地方**，在那里修。

- 状态不一致：找出谁拥有这份状态，收敛到一个 owner；
- 边界错误：在边界解析/校验，内部信任类型；
- 并发问题：先消除共享，再考虑串行化；
- 反复失败：写下一个前提，直接验证前提，而不是再换一个补丁。

Guard 只有在它处理的状态是合法状态时才算修复；否则只是把问题藏起来。

## 反例

- 加 `try/catch` 让错误消失；
- 加重试掩盖竞态；
- 在调用方到处判空，而不是让非法状态不可表达；
- 同一方法失败两次，继续换参数试第三次。
